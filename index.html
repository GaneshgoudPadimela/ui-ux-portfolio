How I Work

Design process

Design and code are one loop in my work — prototypes are validated with users, then implemented as maintainable, tested components.

1

Evaluate

Audit existing screens, navigation, and workflows with users and stakeholders; find where hierarchy and interaction break down.

2

Wireframe & Prototype

Figma wireframes, mockups, and interactive prototypes to test alternatives early through structured user reviews.

3

Systematize

Turn patterns into a documented design system — typography, color, spacing, icons, and reusable components.

4

Build

Production Vue.js within MVVM architecture, responsive HTML5/CSS3, REST API integration, and Git-based code reviews.

5

Make it inclusive

WCAG accessibility, internationalization with layouts that handle text expansion, and role-based navigation and controls.

6

Test & Hand Off

Automated and regression testing, UI architecture documentation, component guidance, and developer knowledge-transfer sessions.
